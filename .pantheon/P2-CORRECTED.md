## E. Surprises the roadmap does not mention

Cross-cutting, ordered by how likely they are to bite:

1. **A route cannot set a CSP in this app.** `SecurityHeadersMiddleware` overwrites any route-set `Content-Security-Policy` (starlette's `MutableHeaders.__setitem__` replaces duplicates). `routes/emoji_routes.py:43`'s `"Content-Security-Policy": "sandbox"` is already dead at the wire — yet pinned by two tests that call the endpoint with no middleware. Any task anywhere that adds a CSP at a handler silently does nothing.
2. **Missing *wiring*, not just missing markup, is the root cause behind P2-19 and half of P2-20.** `admin.js:3152-3156` `inits` omits `initWebhookForm` and `initRag`; `:3164-3171` `refreshAll` omits `loadWebhooks`, `loadFeatures` and `loadRag`. Five entries. Adding HTML without them yields a panel that renders empty and never fetches.
3. **`admin.js` is not uniformly unguarded.** MCP and token loaders/inits already `if (!x) return;` with comments like "MCP form not present in this build". RAG/features/webhooks do not — and where they have a catch, it re-dereferences the same null and re-throws. The only two `/* silent */` catches in the file are `:798` and `:2203`, both in tool-state savers, neither a webhook function.
4. **python-magic is Docker-only** (`Dockerfile:84`, absent from `requirements.txt` *and* `requirements-optional.txt`). On any pip/venv install `file_detector is None`, `detect_content_type` falls back to `mimetypes` — which is exactly the table that decides P2-06's black hole membership, and which returns `text/javascript` for `.js` (not in the blocked set). Reason about uploads from mimetypes, not from libmagic, unless you are reasoning about the image.
5. **All MIME reasoning about uploads is about a 1 KiB prefix** (`upload_handler.py:288`).
6. **A second admin gate exists that the roadmap never names:** `_ADMIN_TOOLS` at `src/tool_execution.py:322-334` (11 names) is checked at `:847`, *before* `is_public_blocked_tool` at `:853`, with a different error string. 10. **`services/memory/skill_importer.py:67` defines a second, unrelated `_is_text_file`**, used to filter archive entries during skill import, sitting alongside SSRF/DNS-pinning and path-traversal guards. A grep-driven "widen `_is_text_file`" change will hit it by accident. Do not touch it.
11. **Unknown privilege keys fail open by design** (`src/auth_helpers.py:146-147`, "the UI gates display-side"). Combined with P2-18's finding that the UI gate is itself non-functional, a mistyped or renamed privilege key grants access and nothing downstream catches it.

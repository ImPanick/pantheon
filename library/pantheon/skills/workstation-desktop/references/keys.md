# Keys for the workstation's `computer` tool

`key` takes xdotool key names. Join modifiers with `+`; separate several presses
with spaces (`ctrl+a BackSpace`).

## Names

| Key | Name |
| --- | --- |
| Enter | `Return` |
| Esc | `Escape` |
| Tab / back-tab | `Tab` / `shift+Tab` |
| Backspace / Delete | `BackSpace` / `Delete` |
| Arrows | `Up` `Down` `Left` `Right` |
| Page up / down | `Page_Up` `Page_Down` |
| Home / End | `Home` `End` |
| Function keys | `F1` … `F12` |
| Space | `space` |
| Modifiers | `ctrl` `shift` `alt` `super` |
| Menu key | `Menu` |
| Insert | `Insert` |

## Everywhere

| Do | Keys |
| --- | --- |
| Select all, copy, cut, paste | `ctrl+a`, `ctrl+c`, `ctrl+x`, `ctrl+v` |
| Undo / redo | `ctrl+z` / `ctrl+shift+z` |
| Next / previous field | `Tab` / `shift+Tab` |
| Close a dialog | `Escape` |

## Firefox

| Do | Keys |
| --- | --- |
| Address bar | `ctrl+l` |
| New tab / close tab | `ctrl+t` / `ctrl+w` |
| Next / previous tab | `ctrl+Tab` / `ctrl+shift+Tab` |
| Back / forward | `alt+Left` / `alt+Right` |
| Reload / hard reload | `F5` / `ctrl+shift+r` |
| Web console / inspector | `ctrl+shift+k` / `ctrl+shift+c` |
| Close developer tools | `F12` |
| Find on page | `ctrl+f` |
| Zoom in / out / reset | `ctrl+plus` / `ctrl+minus` / `ctrl+0` |
| Full screen | `F11` |
| Quit Firefox | `ctrl+q` |

## Terminal (xfce4-terminal)

| Do | Keys |
| --- | --- |
| Interrupt the running command | `ctrl+c` |
| Clear the screen | `ctrl+l` |
| Copy / paste | `ctrl+shift+c` / `ctrl+shift+v` |
| Paste the selection | `shift+Insert` or `middle_click` |
| New tab / close tab | `ctrl+shift+t` / `ctrl+shift+w` |
| Bigger / smaller text | `ctrl+plus` / `ctrl+minus` |

`ctrl+c` and `ctrl+v` are the shell's own keys in a terminal, not copy and
paste. Text is selected with `drag` (or `double_click` / `triple_click`).

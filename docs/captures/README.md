# Hand captures

Pictures here were taken by hand from a running build, because the automated run in
`scripts/showcase/capture.py` can't produce them. Everything in `docs/media/` comes from that
script; nothing in this folder does.

| File | Shows | Why it's by hand |
|---|---|---|
| `android-galaxy-s25-ultra.webp` | A Samsung Galaxy S25 Ultra profile on Android 15 (Google Play developer image), live in the workspace column with the person in control, beside the chat and the workstation screen. Dev build, macOS on Apple Silicon. | Android boots only with a hardware hypervisor (Hypervisor.Framework, WHPX or KVM), which the screenshot run doesn't have. |

The contact shown on the phone is a test entry. Replace a capture by taking it again from a
current build; don't edit the pixels.

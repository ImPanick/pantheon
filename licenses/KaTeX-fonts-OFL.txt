KaTeX fonts — SIL Open Font License 1.1

KaTeX's *code* is MIT (licenses/KaTeX-MIT-LICENSE.txt). Its *fonts* are not.
Every one of the 20 font files shipped in static/lib/katex/fonts/ declares the
SIL Open Font License 1.1 in its own `name` table (nameID 13), and every one
declares a Reserved Font Name. Crediting them as MIT-only understates both the
copyright holders and the licence.

Provenance of this file, so it can be re-derived rather than trusted:

  * The 12 copyright/Reserved-Font-Name blocks below are reproduced verbatim from
    nameID 13 of the shipped .woff2 files themselves — the copyright holders'
    own metadata, read out of static/lib/katex/fonts/*.woff2 in this repo.
    Those blocks incorporate the OFL by reference, not by quotation.
  * The OFL 1.1 text that follows them is byte-identical to
    licenses/FiraCode-OFL.txt from the divider line onward
    (SHA-256 ebc109078c06f79a…, 4,128 bytes), and to SIL's own published
    OFL.txt at openfontlicense.org. licenses/OpenDyslexic-OFL.txt carries the
    same licence but is stored with CRLF line endings, so it hashes
    differently (4,214 bytes) — compare against the FiraCode copy, not that
    one, or the check will look like tampering when it is only line endings.
  * No licence text here was written by hand — only this provenance note and
    the face inventory above it, both of which are checkable against the files.

The font files are shipped unmodified. Do not subset, rename, re-hint or
re-generate them: OFL §3 forbids any Modified Version using a Reserved Font
Name, and all 12 families below declare one.
